# Library

A responsive online library landing page built with HTML, CSS, and JavaScript. The project features a modern homepage layout, book highlight sections, featured books, recent books, and a mobile-friendly navigation menu.

## Preview

Library is designed as a polished front-end project for showcasing an online book platform. Users can browse featured books, view pricing, and navigate through the page using a clean responsive interface.

## Features

* Responsive landing page
* Desktop navigation
* Mobile hamburger menu
* Hero section with call-to-action button
* Highlight cards explaining platform benefits
* Featured books section
* Recent books section
* Book cards with images, ratings, and prices
* Font Awesome icons
* Footer navigation

## Built With

* HTML5
* CSS3
* JavaScript
* Font Awesome

## Getting Started

To run this project locally:

1. Clone the repository.

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

2. Open the project folder.

```bash
cd YOUR-REPOSITORY
```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for a smoother development experience.
